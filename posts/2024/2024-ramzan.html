Rule-Based vs ML Chatbots: Lessons Learned from Early NLP Projects

March 15, 2024 • 2 min • Muhammad Taha Nasir

From deterministic state machines to generative LLM pipelines: what building early NLP projects reveals about the shift in conversational software.

Building conversational systems across three distinct paradigms in early 2024 highlights how software handles human input variations.

Rule-based regular expression trees provide strict deterministic responses but break under syntactic changes, while intent-based ML classifiers and generative LLM pipelines introduce adaptability.

Under the Hood: Three NLP Generations

Implementing rule-based pattern matching alongside transformer token generation: 

# Generation 1: Rule-Based Fragility with Regular Expressions
import re

def rule_based_bot(user_input):
    if re.search(r"\b(hello|hi|hey)\b", user_input, re.I):
        return "Hello! How can I assist you today?"
    elif re.search(r"\b(hours|open|schedule)\b", user_input, re.I):
        return "Our hours are 9 AM to 5 PM."
    return "Fallback: Unrecognized input pattern."

The Systems Engineer Reality Check

Nesting dozens of conditional regular expression rules leads to complex codebases that are difficult to update or extend.

Nested Regex Monolith vs Generative Context Mesh:

Generative models parse fluid human language into structured data, allowing underlying business logic to execute reliably.

Local Inference & Hardware Stress Test

Running local intent classifiers (such as SpaCy or Scikit-learn models) uses minimal CPU resources, while running local quantized 7B LLM models increases VRAM allocation and memory bandwidth requirements.

Selecting appropriate model sizes balances system performance with response accuracy.

Architectural Takeaways & Hybrid Pipelines

Modern conversational software uses hybrid architectures: generative models extract intent from user inputs, while deterministic state engines handle critical transactions.

Understanding these trade-offs ensures conversational applications stay reliable and maintainable.
