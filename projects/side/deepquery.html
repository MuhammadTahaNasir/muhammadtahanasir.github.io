🧠 DeepQuery: AI-Powered SQL Optimization Console

March 2 2026 • Muhammad Taha Nasir
View Source Code

Project Overview

DeepQuery is a deep learning-powered intelligence console designed to bridge the gap between machine learning and database engineering. Relational databases can execute a single logical data query in dozens of syntactically valid ways, but execution efficiency can vary dramatically based on indexing, join order, and structural composition. DeepQuery walks SQL Abstract Syntax Trees (AST) and profiles execution costs to extract a 14-dimensional feature vector, passing it through a 4-layer Artificial Neural Network (ANN) to predict performance bottleneck rankings before queries are executed.

Equipped with an interactive web dashboard and Explainable AI (XAI) heuristics, the system predicts and compares query efficiency side-by-side, saving administrators hours of trial-and-error database testing.

Situation

In high-throughput enterprise databases, poor query structures lead to server lockups, slow response times, and high infrastructure costs. Determining whether an alternate SQL formulation is more efficient usually requires running the queries directly. In production databases, running untested, complex analytical queries can cause immediate performance degradation or service outages. There was a critical need for an offline, predictive model that could analyze queries statically and estimate performance costs before physical execution.

Task

Build a machine learning platform that evaluates up to 8 candidate SQL formulations statically and ranks them. The system needs to parse SQL text structures, generate execution plan costs, feed standardized inputs into a deep learning neural network, and present Explainable AI warnings alongside numeric execution score estimates.

Actions

  • Engineered Neural Network Architecture: Designed and trained a 4-layer Sequential Artificial Neural Network (Dense MLP) in Keras, mapping extracted query features to normalized performance scores from 5.0 to 99.0.
  • Built AST Feature Extractor: Programmed a SQL Abstract Syntax Tree (AST) token walker to parse and extract structural database heuristics (joins count, table references, WHERE clauses, and scalar functions).
  • Integrated Explainable AI (XAI): Developed a heuristic heuristics diagnostic engine that automatically triggers warnings (e.g. index bypass penalties, SELECT * warnings) and highlights scan efficiencies.
  • Created 3-Tier Benchmarking Suite: Structured progressive SQLite databases ranging from a synthetic baseline to dvd rental schemas, and industry-standard TPC-H analytical benchmarks.
  • Developed Web Dashboard: Programmed a Flask application with SVG progress gauge rings, execution comparison graphs, and real-time toast alerts for query profiling.

Results

DeepQuery successfully evaluates multi-candidate SQL formulations with a neural network performance score of R² = 0.4256, a Mean Absolute Error (MAE) of 0.1127, and Root Mean Squared Error (RMSE) of 0.1659. By identifying non-optimal join patterns and scalar indices statically, the console allows developers to catch performance bottlenecks early during query drafting, preventing slow executions in production environments.

Tech Stack

  • Python (3.10+): Primary coding language.
  • TensorFlow & Keras: Frameworks used to build and compile the 4-layer Sequential MLP.
  • Flask: Micro web framework serving the analysis REST API and developer console.
  • SQLite: Relational database engine powering the 3-tier progressive benchmark suite.
  • NumPy & Pandas: Scientific computing libraries for feature extraction matrices and dataset preparation.
  • Scikit-Learn: Standard preprocessing scaling tools.
