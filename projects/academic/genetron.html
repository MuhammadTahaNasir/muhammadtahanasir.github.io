Genetron: 5G Tower Placement Optimizer

May 9 2026 • Muhammad Taha Nasir
Source Code

Project Overview

Genetron is a spatial AI and optimization platform built to solve the 5G tower placement paradox: the challenge of maximizing population coverage while minimizing interference and deployment cost across dense urban environments. It combines a multi-objective NSGA-II genetic algorithm core with a high-fidelity vectorized signal propagation engine, real-time spatial visualizations, and direct OpenStreetMap data ingestion to produce mathematically optimal tower placement strategies.

Developed as the Spring 2026 End-of-Semester AI Project, Genetron simulates how telecom operators can place a fixed number of 5G base stations across a city to maximize network efficiency, reduce dead zones, and minimize signal overlap, all at the same time.

Situation

Telecom operators face a combinatorially explosive placement problem: given a dense urban grid with thousands of candidate sites, buildings causing signal shadows, and competing objectives (coverage, interference, cost), finding the optimal tower configuration is computationally intractable with brute-force methods. Existing tools either oversimplify propagation physics or ignore multi-objective trade-offs entirely, leaving engineers with suboptimal heuristics.

Task

Design and implement a full-stack spatial AI platform that:

  • Ingests real OpenStreetMap building geometries to model signal diffraction and shadowing.
  • Runs a vectorized SNR propagation engine across high-resolution urban grids.
  • Applies NSGA-II to simultaneously optimize coverage, interference, and cost objectives.
  • Renders interactive spectral heatmaps and tower cluster maps in real time.
  • Supports side-by-side scenario comparison (e.g., Coverage Focus vs. Cost Efficiency).

Actions

  • Architected a FastAPI backend with a modular solver core separating GA logic, fitness evaluation, and propagation modeling.
  • Implemented the GN-NSGA-II solver with tournament selection, elitism, and Pareto-front ranking across three simultaneous fitness objectives.
  • Built a vectorized propagation engine using NumPy to compute SNR matrices via Path Loss and Urban Diffraction models at scale.
  • Developed a Python data pipeline (Pandas + GeoPandas) to ingest and pre-process OSM building geometries into signal shadow masks for Peshawar and other urban grids.
  • Built the React frontend with D3.js for real-time spectral heatmap rendering and Framer Motion for animated tower cluster transitions.
  • Implemented a comparative analysis module allowing dynamic side-by-side scenario evaluation with live metric deltas.
  • Styled the entire UI with Tailwind CSS and Lucide Icons for a clean, data-dense dashboard aesthetic.
  • Coordinated a three-person team across frontend, backend, and data pipeline tracks with clear API contracts and shared data schemas.

Results

Genetron achieved a simulated peak coverage of 99.4% with a network efficiency score of 84.2% across the Peshawar urban grid, processing 1,240 candidate nodes through the GN-NSGA-II solver. The platform demonstrated that multi-objective evolutionary optimization can outperform single-objective greedy placement by a significant margin, producing Pareto-optimal configurations that no single-metric approach could discover.

The project deepened my expertise in evolutionary computation, vectorized scientific computing, spatial data engineering, and full-stack AI system design.

  • Lucide Icons: Consistent iconography across the dashboard.
  • FastAPI (Python): High-performance backend serving the solver API.
  • Uvicorn: ASGI server for the FastAPI application.
  • NumPy: Vectorized SNR matrix computation and propagation math.
  • NSGA-II (Custom): Multi-objective genetic algorithm with tournament selection and elitism.
  • Pandas & GeoPandas: OSM data ingestion and urban grid pre-processing.
  • OpenStreetMap: Real building geometry source for diffraction modeling.
