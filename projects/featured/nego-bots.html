NEGO BOTS: AI-Driven Negotiation Simulator

Apr 30 2026 • Muhammad Taha Nasir

Project Overview

Nego Bots is an interactive web-based simulator where users can watch AI models battle over pricing, or step into the arena themselves and test their haggling skills against a mathematically ruthless AI Seller. It bridges Human Psychology with Reinforcement Learning, featuring a custom Gymnasium environment where multi-turn bargaining behaviors like anchoring and strategic bluffing naturally emerge without any domain-specific programming.

Situation

Traditional automated negotiation systems rely on brittle, hand-crafted heuristics that fail to adapt in dynamic environments. Conversely, human negotiators deploy sophisticated tactics by exploiting information asymmetry and adjusting strategies dynamically based on time pressure. The challenge was determining if an AI agent, trained merely through trial-and-error in a simulated environment, could independently discover these same psychological tactics from a pure profit motive.

Task

The goal was to design a robust Multi-Agent Reinforcement Learning (MARL) framework and build a negotiation simulation environment to train a Buyer and a Seller agent using self-play. The agents needed to negotiate effectively across varying financial constraints using a unified numerical reward system. Furthermore, the findings and live agent interactions needed to be accessible via an interactive web dashboard for real-time visualization.

Actions

  • Designed a custom multi-turn bargaining environment using the Gymnasium framework with a novel normalized interval (Scale-Invariant Ratio Model).
  • Trained competitive Buyer and Seller agents using Proximal Policy Optimization (PPO) and a Self-Play curriculum over millions of simulated interactions using Stable-Baselines3.
  • Developed reward functions featuring a relative surplus metric to enforce a time friction penalty (deadline effect).
  • Analyzed behavioral metrics systematically to quantify the spontaneous emergence of tactical behaviors, such as the anchoring effect and deadline-driven concessions.
  • Built an interactive Flask web dashboard to host live negotiation simulations, integrating a neobrutalist UI and rendering live concession charts with Chart.js.

Results

The agents successfully converged from random exploration to stable bargaining strategies, demonstrating complex, human-like tactics. They independently discovered anchoring techniques and accelerated concessions as deadlines approached, validating the theoretical models. The scale-invariant architecture allowed effective generalization across varying price magnitudes, rendering the framework viable for practical automated procurement and pricing optimization solutions.

Tech Stack

  • Python: Core application language driving both AI models and the backend API.
  • Gymnasium: Employed for building the custom multi-turn negotiation simulation environment.
  • PyTorch & Stable-Baselines3: Utilized for training RL agents using Proximal Policy Optimization (PPO).
  • Flask: Handled the backend server, API routing, and state persistence for the interactive simulation.
  • HTML5 / CSS / Vanilla JS: Rendered the striking neobrutalist frontend UI, complete with dynamic chat interactions.
  • Chart.js: Generated live, real-time concession analytics graphs to track bargaining history.
