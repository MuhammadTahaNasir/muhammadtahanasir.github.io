RescueAI: ریسکیو اے آئی

May 9 2026 • Muhammad Taha Nasir
View Source Code Live Demo

Project Overview

RescueAI is a bilingual (English/Urdu) AI-powered emergency response platform built for Pakistan. Anyone can trigger a one-tap SOS alert that sends their GPS coordinates, auto-assigns a responder unit with a live ETA, and immediately connects them to ARIA, an AI assistant that provides real-time, voice-enabled guidance for CPR, bleeding control, burns, choking, and more. The entire platform works in both English and Urdu, with full RTL layout support.

Situation

In Pakistan, emergency response infrastructure is fragmented and slow. During a crisis like a cardiac arrest, a road accident, or a fire, people lose precious minutes navigating government portals or waiting on hold. There was no single platform that combined instant location-based alerting, responder dispatch, and AI-guided first-aid instructions in a language most Pakistanis speak natively: Urdu.

Task

Design and build a full-stack emergency response platform that works under pressure: one-tap SOS with GPS, structured incident reporting with AI-generated response protocols, live dispatch tracking, and a conversational AI assistant (ARIA) that can be operated entirely by voice in both English and Urdu, with spoken responses read back to the user.

Actions

  • Built a FastAPI backend with async endpoints for SOS alerts, incident reports, and live tracking, designed for zero-latency under emergency load.
  • Integrated Groq LLaMA 3.3 70B for ARIA's conversational AI pipeline, providing fast, multilingual emergency guidance.
  • Used Groq Whisper v3 for voice input transcription, chosen for its superior Urdu accuracy over alternatives.
  • Implemented Google gTTS for Urdu text-to-speech so ARIA can speak responses back in correct Urdu script rendering.
  • Built the frontend in React 19 + Vite with Tailwind CSS v4, including a full RTL layout switch for Urdu mode.
  • Designed the Emergency SOS flow: one tap captures GPS coordinates, assigns the nearest responder unit, and returns a live ETA.
  • Built the Incident Reporting module with AI-generated response protocols per incident type (fire, medical, accident, etc.).
  • Deployed the frontend on Vercel and the backend on a separate service for decoupled, high-availability architecture.

Results

RescueAI is live at rescueai-pakistan.vercel.app. The platform delivers sub-second SOS alert processing, full bilingual UI with RTL Urdu support, and hands-free voice operation through ARIA. It demonstrates a practical, deployable model for AI-assisted emergency response in underserved markets where language and infrastructure barriers are critical obstacles.

Tech Stack

  • Groq LLaMA 3.3 70B: Core AI model powering ARIA, fast inference with strong multilingual (Urdu/English) support.
  • Groq Whisper v3: Voice-to-text transcription with best-in-class Urdu accuracy for hands-free operation.
  • Google gTTS: Urdu text-to-speech for ARIA's spoken responses with correct script rendering.
  • FastAPI: High-performance async Python backend for emergency-grade API endpoints.
  • React 19 + Vite: Modern, snappy frontend with fast HMR and optimized builds.
  • Tailwind CSS v4: Utility-first styling with RTL support for the Urdu layout.
  • Web Speech API: Browser-native speech recognition for English voice input.
  • Vercel: Frontend deployment with global CDN for low-latency access across Pakistan.
